# BMI Calculator

A simple and interactive Body Mass Index (BMI) calculator built using Python and Streamlit.

🔗 **Live Demo:** [fahadmzn.streamlit.app](https://fahadmzn.streamlit.app)

## Features
- Calculates BMI based on weight and height inputs.
- Fast, clean, and user-friendly web interface.

## Built With
- Python
- Streamlit
